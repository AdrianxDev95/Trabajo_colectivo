# Trabajo_colectivo
Este proyecto, sera para el trabajo colectivo de Evelyn:
Creación de Ramas y Funcionalidades:
Se creó una nueva rama (nueva-funcionalidad), donde se realizaron modificaciones independientes y se registraron con commits.

Subida de Cambios y Pull Request:
Los cambios se subieron al repositorio remoto y se solicitó su revisión mediante un Pull Request (PR) en GitHub.

Revisión y Fusión de Cambios:
El compañero Lujan revisó y aprobó el PR antes de fusionarlo con la rama principal (main), garantizando la calidad del código.

Resolución de Conflictos:
Se simuló y resolvió un conflicto al fusionar ramas, editando manualmente el archivo afectado y realizando un nuevo commit.
